# Стилист — Telegram-бот

Публичный бот-стилист: присылаешь вещь текстом или фото, получаешь разбор
по 16 пунктам и вердикт «брать / не брать». Основной провайдер — Gemini API,
архитектура мультипровайдерная (DeepSeek, Kimi, Claude, GPT подключаются позже).

Бот открыт для всех, но работает **на ключе пользователя**: каждый приносит свой
бесплатный ключ Gemini через `/apikey`. Так расход и лимиты у всех свои,
и один активный человек не выжигает квоту остальным.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

cp .env.example .env
# обязателен только TELEGRAM_BOT_TOKEN

.venv/bin/python bot.py
```

Необязательное в `.env`:

| Переменная | Зачем |
| --- | --- |
| `OWNER_USER_ID` | доступ к `/stats` и работа без личного ключа |
| `GOOGLE_API_KEY` | резервный ключ владельца; остальным не выдаётся |
| `ENCRYPTION_KEY` | мастер-секрет для шифрования чужих ключей |

Без `ENCRYPTION_KEY` секрет выводится из токена бота. Смена токена делает
сохранённые ключи нечитаемыми — пользователям придётся ввести их заново.

База (SQLite) создаётся при первом старте.

## Ключи пользователей

Ключ приходит в чат обычным сообщением, поэтому `/apikey`:

1. удаляет сообщение с ключом сразу, до всех проверок;
2. проверяет ключ живым вызовом `count_tokens` — он не тратит квоту, но требует
   валидной авторизации, иначе неверный ключ всплыл бы только на первом разборе;
3. хранит ключ в БД зашифрованным (Fernet), в ответах показывает только маску.

`/apikey_off` удаляет ключ, `/forget` — все данные пользователя.

## Команды бота

| Команда | Что делает |
| --- | --- |
| `/start`, `/help` | приветствие и подсказки |
| `/apikey`, `/apikey_off` | свой ключ Gemini |
| `/profile`, `/setup` | параметры фигуры (FSM-опрос) |
| `/wardrobe`, `/add`, `/remove` | гардероб |
| `/wishlist`, `/wish`, `/bought`, `/unwish` | отложенное к покупке |
| `/history`, `/show <id>` | журнал разборов и полный текст |
| `/model` | какая модель анализирует |
| `/cancel` | прервать диалог |
| `/forget` | удалить все свои данные |
| `/stats` | только владельцу: пользователи и расход токенов |

Любое сообщение без команды — описание вещи на анализ. Фото и альбомы тоже.

## Замеры

В `/profile` вводятся **обхваты** (лентой вокруг тела). Полуобхват бот считает
сам и показывает модели оба числа: продавцы указывают замеры вещи по плоскости,
то есть в полуобхвате, и без пересчёта пункт 5 ошибался бы вдвое.
Полуобхват можно ввести и явно — «пол 48».

## Тесты

```bash
.venv/bin/python -m pytest
```

## Структура

```
bot.py                 точка входа, DI, polling
config.py              pydantic-settings, валидация .env
handlers/              start, api_key, admin, profile, wardrobe, wishlist,
                       history, model_selection, analysis
filters/owner.py       IsOwner — точечно на админ-командах
services/llm/          base (интерфейс), gemini_provider, factory
services/              llm_router, prompt_builder, response_parser, measurements,
                       api_keys, crypto, media_group_buffer, image_utils, text_utils
db/                    models, database, crud/
prompts/               system_prompt, behavior_rules, output_format
middlewares/           db_session
```

Промпт собирается из `prompts/` плюс живые данные: параметры, гардероб, вишлист,
последние вердикты. Модель возвращает текст и блок `===DATA===` с JSON —
`response_parser` делит их, поэтому парсер один для всех провайдеров.
